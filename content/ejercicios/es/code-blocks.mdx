[`rehype-pretty-code`](https://github.com/atomiks/rehype-pretty-code) es un plugin de Rehype impulsado por el
resaltador de sintaxis [`shiki`](https://github.com/shikijs/shiki) que proporciona hermosos bloques de código para Markdown o MDX.

## Resaltado de Calidad de Editor

Disfruta de la precisión y granularidad del motor de resaltado de sintaxis de VS Code y
la popularidad de su ecosistema de temas: ¡usa cualquier tema de VS Code que desees!

## Números de Línea y Resaltado de Línea

Dibuja atención a una línea particular de código.

```js {4} showLineNumbers
import { useFloating } from "@floating-ui/react";

function MyComponent() {
  const { refs, floatingStyles } = useFloating();

  return (
    <>
      <div ref={refs.setReference} />
      <div ref={refs.setFloating} style={floatingStyles} />
    </>
  );
}
```
